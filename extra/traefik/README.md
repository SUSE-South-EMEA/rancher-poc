# Traefik Integration for Rancher

Ce répertoire contient les scripts et fichiers de configuration pour intégrer Traefik avec Rancher.

## Scripts

- **`install-traefik-rancher.sh`** - Script principal d'installation de Traefik pour Rancher
- **`configure-traefik-dns-challenge.sh`** - Configuration du défi DNS pour Traefik (Let's Encrypt)

## Fichiers de configuration

- **`traefik-rancher-config.yaml`** - Configuration Kubernetes pour Traefik
- **`traefik-rancher-docker-compose.yml`** - Configuration Docker Compose pour Traefik
- **`traefik-rancher-kubernetes.yaml`** - Manifestes Kubernetes pour Traefik
- **`traefik-rancher-static.yml`** - Configuration statique pour Traefik

## Documentation

- **`INSTALL-TRAEFIK-RANCHER.md`** - Instructions complètes d'installation et de configuration

## Utilisation

Consultez `INSTALL-TRAEFIK-RANCHER.md` pour les instructions détaillées d'installation et de configuration de Traefik avec Rancher.
