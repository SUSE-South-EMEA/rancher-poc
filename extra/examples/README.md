# Exemples de Scripts

Ce répertoire contient des exemples de scripts spécifiques à des hôtes ou des cas d'usage particuliers.

## Fichiers

- **`add-ssh-key-172.16.3.23.sh`** - Exemple de script pour ajouter une clé SSH sur un hôte spécifique
- **`install-ca-172.16.3.23.sh`** - Exemple de script pour installer le certificat CA sur un hôte spécifique
- **`COMMANDES-SSH-172.16.3.23.txt`** - Exemple de commandes SSH pour un hôte spécifique

## Utilisation

Ces fichiers servent d'exemples et peuvent être adaptés pour vos propres besoins. Remplacez les adresses IP et les configurations selon votre environnement.

## Note

Ces scripts sont spécifiques à un hôte particulier (172.16.3.23) et doivent être adaptés avant utilisation dans d'autres environnements.
